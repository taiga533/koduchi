# ADR 0009: ウィンドウモデルとタイトルバー

- ステータス: 承認
- 日付: 2026-08-30

## 状況

デザインの接続作成画面（状態 5g）には「**1つの接続が1つのウィンドウになります**」と明記されており、サイドバー最下部にも「別の接続を新しいウィンドウで開く」がある。これは明示的な設計判断である。

またデザインは 42px のカスタムタイトルバーを持ち、そこに macOS の信号機 3 ボタン・接続名・`⌘K` 検索ボックス・Ask AI ボタンを並べている。

`node_modules/@tauri-apps/cli/config.schema.json` を確認した事実:

- `titleBarStyle`: "The style of the macOS title bar."
- `trafficLightPosition`: "The position of the window controls on macOS. **Requires titleBarStyle: Overlay and decorations: true.**"
- `hiddenTitle`: "If `true`, sets the window title to be hidden on macOS."

つまり Tauri の「タイトルバー上に UI を置く」機能は、**ネイティブの信号機を残したまま**位置だけをずらし、Web コンテンツを最上部まで描くものである。

## 決定

**1 接続 = 1 Tauri ウィンドウ**とする。`WebviewWindow` を動的に生成し、Rust 側の接続プール（[[0003-結果セットのカーソル保持と接続プール]]）をウィンドウラベルで分離する。

タイトルバーは次の設定で実装する。

```json
{
  "decorations": true,
  "titleBarStyle": "Overlay",
  "hiddenTitle": true,
  "trafficLightPosition": { "x": 14, "y": 15 }
}
```

42px ヘッダーの縦中央に信号機が来るよう `y` を調整し、ヘッダー左端は信号機の分だけ空ける。ドラッグ領域は `data-tauri-drag-region` で指定する。

**結果ペインのタブは、内容があるときだけ出現する動的タブ**とする。通常は「結果」1 つだけが表示され、その場合はタブ行を描画せず、32px ヘッダーには行数と所要時間（`142 行 · 84 ms`）だけが残る。エラーや `DBMS_OUTPUT` があれば「メッセージ」が、`⌘E` を押せば「実行計画」がその場で追加される。

## 理由

- 1 接続 = 1 ウィンドウはデザインの明示的な判断であり、本番と開発を並べて見られる実利がある。Tauri v2 のマルチウィンドウは素直に動く。
- macOS の信号機はホバー時のアイコン表示・長押しのフルスクリーンメニューなど挙動が細かく、自前再現は割に合わない。`trafficLightPosition` を使う限り、見た目はデザインとほぼ同じになる。
- 結果ペインは基本的に結果だけを見る場所であり、常時 3 つのタブが並ぶのは情報として重い。一方でメッセージと実行計画には置き場所が必要である。動的タブが両方を満たす。

## 却下した案

**単一ウィンドウでタイトルバーから接続を切り替える**: 実装は大幅に簡単だが、デザインの文言と正面から矛盾する。

**`decorations: false` で信号機も自前描画する**: `trafficLightPosition` が使えなくなり、ネイティブ挙動も失われる。macOS のみが対象（[[0001-oracle接続方式]]）なので、他 OS で見た目を揃えるという動機も無い。

**結果ペインのタブを完全に廃止する**: メッセージと実行計画の置き場所が消える。エディタと結果ペインの間に折りたたみパネルを置く案もあるが、デザインの 3 パネル構成を崩す。

**デザインどおり固定 3 タブ（結果 / メッセージ / 履歴）**: 履歴はサイドバーへ一本化した（[[0005-クエリ履歴とセッション復元のsqlite]]）ため、そのままでは成立しない。

## 結果

- ウィンドウの位置とサイズは `tauri-plugin-window-state` で復元する。
- ウィンドウごとに独立した zustand ストアが存在する。ストア間で共有されるのは履歴 SQLite だけである。
- タイトルバー中央の `⌘K` 検索ボックスは表示するが操作できない（コマンドパレットは器のみ）。`⌘K` と `⌘I` のキーバインドは割り当てない。→ この 1 点は [[0018-保存済みクエリとコマンドパレット]] で覆した。検索ボックスは押せるようになり、`⌘K` はコマンドパレットに割り当てた。`⌘I` の予約は残る。
