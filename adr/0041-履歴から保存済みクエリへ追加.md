# ADR 0041: 履歴から保存済みクエリへ追加

- ステータス: 承認
- 日付: 2026-09-27

## 状況

保存済みクエリへ積む道は `⌃⌘S`（とコマンドパレット）だけで、対象はエディタの SQL だった（[[0018-保存済みクエリとコマンドパレット]]）。利用者は、過去に流した SQL を履歴の行から後で取っておきたいと言っている。

履歴は全接続で 1 つの表であり（[[0005-クエリ履歴とセッション復元のsqlite]]）、「全接続」に切り替えると他の接続で流した SQL も並ぶ。また同じ SQL が何度も並ぶ。

決めることは 4 つある。

1. 入口をどこに置くか
2. 保存に添える接続名を、履歴の行のものにするか今の接続のものにするか
3. 同じ SQL が既に保存済みのときにどうするか
4. 保存できたことをどう伝えるか

## 決定

### 入口は履歴の行の右クリックメニューだけに置く

`SqlEntryContextMenu` に「保存済みクエリへ追加」を足し、履歴の一覧のときだけ出す（保存済みクエリ自身には出さない）。**行にボタンは足さない。**行には既に押す場所が 2 つ（本体でエディタへ入れる、`✕` で消す）あり、たまにしか使わない操作のために押し間違いの的を増やさない。右クリックは [[0038-右クリックメニューの追加]] で一覧の行に入れたばかりで、発見の道もそこにある。

### 名前を尋ねるダイアログと書き込みはエディタからの保存と共有する

仲介者 `src/mediator/savedQuery.ts` に `saveQueryFromHistory` を足す。`saveQueryFromEditor` と共有するのは、同じ SQL を探して名前を尋ねる `askQueryName` と、ストアの `save` である。入口ごとに違うのは「どの SQL を」「どの接続名で」の 2 点だけで、それぞれの関数に残す。

### 添える接続名は履歴の行のものにする

その SQL が実際に流れた先だからである。今の接続名を付けると、全接続の履歴から拾った本番の SQL が、保存済みの「この接続のみ」で開発の窓に混ざる。今の接続に依らないため、名前を尋ねている間に切断されても積む（エディタからの保存は今の接続名を添えるので、切断されていれば積まない。こちらは変えない）。

名前の既定値は SQL の空行でない最初の行を、空白を詰めて 40 文字で切ったものにする。履歴の一覧が 1 行目を見出しにしており、それと結び付くためである。

### 同じ SQL が保存済みなら告げるが、保存は止めない

尋ねる前に、前後の空白を除いて本文が一致する保存済みクエリを**全接続から**探し、見つかればダイアログに「同じ SQL が「〇〇」として保存済みです」と出す。保存ボタンは押せるままにする。[[0018-保存済みクエリとコマンドパレット]] のとおり名前は目印であって鍵ではなく、同じ SQL を別の名前で持ちたい場合もある。一方で履歴は同じ SQL を何度も並べるため、黙って積むと気付かないうちに増える。

探すのは既存の `list_saved_queries`（部分一致・`like` の打ち消し済み）で当たりを取り、手元で本文の一致を見る。Rust 側には手を入れない。エディタからの保存も同じ判定を通る。

### 保存できたことは履歴の一覧の上に一言で出す

保存済みの一覧は別のセグメントにあって見えないため、履歴の一覧の上に「「〇〇」を保存済みクエリへ追加しました」を 2.5 秒出す（コピーの一言と同じ長さ）。**積めたときだけ出す。**そのためストアの `save` は積めたかを返すようにした。保存済みの一覧は `save` が読み直すため、切り替えれば並んでいる。セグメントを勝手に切り替えることはしない（続けて履歴から積みたい人の手を止める）。

## 却下した案

**行にホバーで出るアイコンを足す**: 上に書いたとおり、押し間違いの的が増える。

**今の接続名を添える**: 流れた先と違う接続名が付き、保存済みのスコープ切替が嘘をつく。

**同じ SQL なら保存させない、または既存を上書きする**: 別の名前で持ちたい場合を塞ぐ。上書きは [[0018-保存済みクエリとコマンドパレット]] が退けた「保存したつもりが上書きだった」事故を作る。

**保存したら保存済みのセグメントへ切り替える**: 積めたことは分かるが、履歴を続けて辿る手が止まる。

## 結果

- `AskRequest` の `saveQuery` に `existingName` が増えた。`SaveQueryDialog` はそれを受けて一言を出す。
- `savedQuery` ストアの `save` は `Promise<boolean>` を返し、`findBySql` が増えた。
- コマンドパレットの履歴の候補からは保存できない。パレットの決めたときの動きは「SQL を今のタブへ入れる」1 つである（[[0018-保存済みクエリとコマンドパレット]]）。
