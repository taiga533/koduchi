# ADR 0038: 右クリックメニューの追加

- ステータス: 承認
- 日付: 2026-09-27

## 状況

小槌の右クリックメニューは 2 か所にしかなかった。スキーマツリー（`SchemaTreeContextMenu.tsx`、ADR 0020・0022）と結果テーブル（`ResultContextMenu.tsx`）である。利用者は「右クリックしても何も出ない、あるいはウェブビューの既定のメニューが出る」場所が多いと感じていた。

コードを見て確かめた事実は次のとおりである。

- **ウェブビューの既定のメニューを止めている箇所は 1 つも無かった。**`contextmenu` を受けていたのは上の 2 部品だけである。WKWebView は、文字の上では「調べる / 翻訳 / コピー / 貼り付け / スペル / サービス」を、何も無い場所では「再読み込み」を出す（開発ビルドでは「要素の詳細を表示」も）。**「再読み込み」を押すとウェブビューが読み直され、フロントエンドの状態（接続・タブ・結果・未コミットの表示）だけが消える。**Rust 側のプールとトランザクションは残るため、画面と実体が食い違う。
- 既存の 2 つのメニューは見た目も `MenuItem` も写しだった。違いは結果テーブルの側だけが焦点を奪わないこと（issue #53）と、ツリーの側だけが見出しを持つことの 2 点。どちらも**画面端での位置の補正を持たなかった**（下端や右端で右クリックするとメニューがウィンドウの外へ切れる）。
- タブ帯には右クリックのメニューが無かった。ADR 0032 は「名前を変える」をメニューに置く案を、「1 項目のためにメニューの仕組みを持ち込むと『閉じる』『他を閉じる』『右側を閉じる』が付いてくる。メニューを作るかどうかは別に決める」として退けている。この ADR がその「別に決める」にあたる。
- 右クリックから呼べる裁定は既にほとんどある: `closeTabAndRelease(tabId)` / `putSqlIntoEditor(sql)` / `openSqlInNewTab(sql)` / `saveActiveTab()` / `saveActiveTabAs()`（後の 2 つは選んでいるタブだけ）。キーの表記は `useShortcutLabel(id)`（ADR 0037）で引ける。

## 決定

### 足した場所

**項目はどれも既存の操作の別の入口である。**新しい裁定は「他のタブを閉じる」「右側のタブを閉じる」と、保存をタブ ID で受ける形への広げの 2 つだけで、どちらも `src/mediator/` に置いた。

| # | 場所 | 項目 | 既存の入口との関係 |
|---|---|---|---|
| 1 | 画面全体（自前のメニューが無い所） | **既定のメニューを止める。**入力欄・`<textarea>`・`contenteditable`（CodeMirror の本文）と、選んだ文字の上では止めない | 入口は増やさない |
| 2 | タブ帯のタブ | 閉じる（`⌘W`）/ 他のタブを閉じる / 右側のタブを閉じる / 名前を変更（`F2`、SQL タブだけ）/ 保存（`⌘S`）/ 名前を付けて保存（`⇧⌘S`）（SQL タブだけ）/ ファイルのパスをコピー（ファイルに結び付いているときだけ） | 閉じるは 1 枚ずつ `closeTabAndRelease` を通す。名前の変更は `F2` と同じ編集の開始。保存は `saveTab(tabId)` / `saveTabAs(tabId)` |
| 3 | 履歴の行 | エディタへ入れる / 新しいタブで開く / SQL をコピー / 削除 | 行の単クリック（`putSqlIntoEditor`）・`openSqlInNewTab`・`✕` と同じ |
| 4 | 保存済みクエリの行 | 上と同じ ＋ 名前を変更 | 名前の変更は鉛筆と同じ行の中の編集 |
| 5 | 結果テーブルの見出し | 列名をコピー / この列をコピー / 列幅を内容に合わせる | セルのメニューの「この列をコピー」、見出しのダブルクリックの `autoFitWidth` と同じ |
| 6 | 結果テーブルの行番号 | セルと同じメニュー（「この列をコピー」を除く）。右クリックした行が選択に掛かっていなければ、先にその行全体を選ぶ | セルのメニューそのもの |
| 7 | メッセージタブのログ 1 件 | SQL をコピー / 新しいタブで開く（実行した SQL のログだけ）/ エラーをコピー（エラーがあるときだけ） | エラーのコピーは `ErrorCopyButton` と同じ文字列を手を加えずに写す |
| 8 | 定義タブの列・制約・索引の行 | 名前をコピー / この行をコピー | 行の写し方は内訳のコピー（`definitionCopy.ts`）と同じ関数を通す |
| 9 | ソース検索の当たり | オブジェクト名をコピー / 当たった行をコピー（行の上だけ） | 新しい裁定は無い |
| 10 | セッションとロックの行 | `SID,SERIAL#` をコピー / 行をコピー | **kill は入れない** |

### 足さない場所

| 場所 | 足さない理由 |
|---|---|
| エディタの本文（CodeMirror） | **既定のメニューを残す。**奪うと「調べる」「翻訳」「スペルと文法」「サービス」「作文ツール」を失い、貼り付けを作り直すにはクリップボードを読む権限まで要る。自前で出したい項目（実行・選択範囲を実行・整形）はどれもキーとパレットに既にある。macOS の再変換はメニューではなくキーで行うため、どちらにしても失われない |
| DDL の内訳・セルの詳細パネル・入力欄 | 文字を選んで写す場所であり、既定のメニューが役に立つ（#1 の条件で残る） |
| タブ帯の何も無い所 | 「新しいタブ」「ファイルを開く」は `＋` とキーで足りる。#1 で「再読み込み」だけは止まる |
| スキーマツリーの見出し行・種別の束 | 項目は変えない（ADR 0020）。種別の束では #1 で既定のメニューが止まる |
| ステータスバー・タイトルバー・サイドバーの空き・分割線・設定画面・各ダイアログ・パレット | 並べる操作が無い |
| セッションの kill | 取り返しの付かない操作を、押したことが分かりにくい右クリックへ置かない（ADR 0020 が `SELECT` の実行を右クリックに置かなかったのと同じ考え）。関所 3 つ（ADR 0017）は行のボタンの先にだけある |
| ソース検索の「定義を開く」「エディタへ挿入」 | 当たりからの移動先は ADR 0021 で決めていない。種別が `SourceKind`（本体を含む）で、定義タブの `ObjectKind` へそのまま繋がらない |
| タブの「Finder で表示」 | 既存の操作ではない（`opener` の `reveal_item_in_dir` の権限を新たに足すことになる）。パスのコピーで代える |

### 共通の器 `ContextMenu`

`src/components/menu/ContextMenu.tsx` に 1 つ作り、既存の 2 つもこれへ寄せた。決まりは 4 つ。

- **焦点を奪わない。**暗幕も項目も押し下げの既定動作を止める（issue #53 の作り）。**スキーマツリーのメニューもこちらへ揃えた。**閉じた後も焦点がツリーの行に残り、`↑` / `↓` がそのまま効く。
- `esc` は `useEscapeKey`（ADR 0031）。外を押す・外で右クリックすると閉じる。ソース検索やセッションのパネルの上で開いたメニューは、`esc` 1 打鍵でメニューだけが閉じる（積みの末尾から閉じる）。
- **画面の端では反対側へ開く。**押した点をメニューの右端・下端に合わせる（macOS のネイティブのメニューと同じ）。反対側へ開いても収まらないほど狭ければ端の余白に寄せる。計算は `placement.ts` の `placeMenu`。
- 項目を選んだら操作を呼んでから閉じる。キーの表記は呼び出し側が `useShortcutLabel` で引いて渡す。`F2` のような割り当て直せないキーは `formatChord` で書く。使えない項目は押せなくするのではなく出さない（ADR 0020 と同じ）。

### 既定のメニューを止める関所

`src/input/nativeContextMenu.ts` の `installNativeMenuGuard` を `main.tsx` で `window` に 1 度だけ張る。自前のメニューを出す部品は自分で `preventDefault` するため、ここはそれ以外の場所だけを受け持つ。

**「選んだ文字の上か」は節点の包含ではなく、選択が描かれている矩形と押した点で決める**（`isOnSelectedText`）。右クリックの的は文字ではなく要素であり、1 つの `<pre>` の中の数語を選んだとき、その `<pre>` は選択に「含まれ」ない。逆に要素が選択と交わるかで見ると、選択を残したまま同じ器の空いた所を押しても真になり、「再読み込み」がまた出る。メッセージタブと定義タブの行も同じ判定で、選んだ文字の上ではウェブビューのメニューに任せる。

### 仲介者

- `tabs.ts` に `closeOtherTabs(tabId)` / `closeTabsToRight(tabId)` を足した。閉じる対象の並びは `tabOrder.ts` の純粋な関数（`otherTabIds` / `tabIdsToTheRight`）が決め、1 枚ずつ `closeTabAndRelease` を `await` する。**書きかけのタブで「閉じない」と答えたらそこで止める。**「閉じない」と答えた人は、残りも閉じてよいかを考え直している。そのために `closeTabAndRelease` は「タブがもう無いか」を返すようにした（取り消されたときだけ偽）。
- `files.ts` の保存を `saveTab(tabId)` / `saveTabAs(tabId)` に広げ、`saveActiveTab` / `saveActiveTabAs` はそれに今のタブを渡す薄い包みにした。**コマンドの表の行は変えていない。**保存先を尋ねている間にタブが閉じられたら書かない。書くのは尋ねた後に読み直した中身である。

### メッセージタブのログの種別

`LogEntry` に `kind: 'statement' | 'notice'` を足した。整形・接続・コミット / ロールバックの報せは `sql` に見出しの文言（「SQL の整形」「接続」「コミット」）を入れており、SQL ではない。「SQL をコピー」「新しいタブで開く」を報せにまで出すと、見出しの文言がエディタへ入る。写すものが無い報せ（「コミットしました」）ではメニューそのものを出さない。

### 1 行のコピーに見出しを付けない

定義タブの行とセッションの行の「この行をコピー」は、画面の欄の並びのタブ区切り 1 行で、**見出しは付けない。**内訳まるごとのコピーが見出しを必ず付けるのは表として貼るためだが（`definitionCopy.ts`）、1 行を写すのは既に貼ってある表へ継ぎ足すか、1 つの素性を伝えるときである。欄の並びと札の付け方は内訳のコピーと同じ関数を通すため食い違わない。

## 理由

- **入口だけを足し、裁定を増やさない。**右クリックはキー・ボタン・パレットと並ぶ入口の 1 つにすぎない。同じ操作に別の裁定があると、片方だけ直す・片方だけ関所を持つ、が起きる（ADR 0035）。
- **ウェブビューの既定のメニューを全面では止めない。**文字を扱う場所の既定のメニューは、小槌が作り直すより良くできている（調べる・翻訳・作文ツール）。止めるのは、画面と実体を食い違わせる「再読み込み」が出る場所だけである。
- **器を 1 つにしたのは、決まり（焦点・`esc`・端の補正）を全部のメニューに等しく効かせるためである。**2 つが写しだったため、焦点を奪わない直し（issue #53）は結果テーブルにしか入っていなかった。

## 却下した案

**エディタの本文も自前のメニューにする**: 実行・整形・コピー・貼り付けを並べられる。しかし上の「足さない場所」のとおり失うものが多く、自前で出す項目はどれもキーとパレットにある。右クリックでしか届かない操作にはならない。

**既定のメニューを全面で止める**: 条件の判定が要らない。しかし入力欄の貼り付けと、選んだ文字のコピー・調べるが消える。

**タブの右クリックでそのタブを選び直す**: 保存が今の `saveActiveTab` のまま使える。しかしメニューを開いただけで結果ペインが入れ替わり、見ていたものが見えなくなる。VSCode もタブの右クリックでは選び直さない。

**「他のタブを閉じる」で書きかけのタブをまとめて 1 度だけ尋ねる**: 打鍵は減る。しかし確認の形が 1 つ増え、`closeTabAndRelease` の関所（ADR 0023）を通らない閉じ方ができてしまう。

**結果テーブルの見出しの右クリックで列を選ぶ**: Excel の真似にはなる。しかし見出しは選択の単位ではなく（ADR README「結果テーブル」）、列の選択は「この列をコピー」で足りる。

## 結果

- 右クリックのメニューが 2 か所から 11 か所になった。器は `ContextMenu` 1 つで、どれも焦点を奪わず、`esc` で閉じ、画面の端で切れない。
- スキーマツリーのメニューは焦点を奪わなくなった。項目と並びは変えていない。
- ウェブビューの「再読み込み」は、文字を扱う場所の外では出なくなった。**開発ビルドの「要素の詳細を表示」も同じ場所では出ない。**開発中に要素を調べるときは、入力欄の上で右クリックするか、Safari の Web インスペクタから開く。
- `closeTabAndRelease` の戻り値が `Promise<boolean>` になった。今までの呼び出し（`✕` / `⌘W`）は戻り値を見ないため振る舞いは変わらない。
- `LogEntry` に `kind` が増えた。ログを積む場所を足すときは、実行した SQL か報せかを選ぶ。
- 操作の持ち主の表: `ResultTable.tsx` 冒頭の表に「行番号を右クリック」「見出しを右クリック」の 2 行を足した。スキーマツリーの表（`CLAUDE.md`）は変えていない。
